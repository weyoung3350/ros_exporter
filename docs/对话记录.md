## 1. 宇树 B2 工业级四足适配（2026-05-02）

### 1.1 背景

仓库已支持 G1（CGO 真集成）+ Go2/B2/ROSMaster-X3（stub）的多机器人骨架，但 `internal/types/b2_types.go` 全是 `// TODO` + 硬编码假数据。本次任务：把 B2 stub 重构为真实集成，部署到 Jetson AGX Thor + 宇树 B2 编号 1401，并配套全栈监控容器化。

参考资料：`/Users/dna/Documents/Develop/claude_prj/AGX-Thor` 项目（Thor 部署画像、网卡/SDK/cyclonedds 配置）。

### 1.2 核心决策（4 轮 brainstorm）

| # | 决策点 | 选择 | 理由 |
|---|-------|------|------|
| 1 | B2 数据源 | DDS（CGO + unitree_sdk2） | 直连 B2 主控最完整，对齐现有 G1 CGO 模式 |
| 2 | 抽象层 | interface + build tag 双隔离 | interface 保扩展性，build tag 解 CGO 在 macOS/CI 编译问题 |
| 3 | 第一版指标 | IMU / 12 关节 / 电池 / 急停 | 砍掉 SDK 不直接给的派生字段（terrain/collision/stability/load）|
| 4 | 部署 | Thor 本机编译 + systemd → 容器化 docker compose | 现场最简，与 OTA Agent 同构；后续容器化全栈 |

附带决策（落到 plan v3）：关节单位 rad、删告警阈值字段、G1 同步重构（零行为变化约束）。

### 1.3 第三方评审（codex）

[`docs/CODEX_REVIEW_REPORT.md`](CODEX_REVIEW_REPORT.md) 给出 3 Critical / 6 Warning / 2 Info。逐条落地：

- **C-1 编译闭环不成立**：Go cgo 不会自动编 `third_party/*.cpp`。改为 `internal/sdk/unitree/b2_sdk.cpp` + Makefile 编静态库 + cgo LDFLAGS 链接（与 G1 同模式）
- **C-2 电池字段假设错**：原 stub 假装能读 health/is_charging/error，实测 BmsState IDL 只有 soc/current/cycle/cell_vol[15]/bq_ntc[2]/mcu_ntc[2]。总电压由 sum(cell_vol) 算
- **C-3 DDS 不会自愈**：wrapper 加 watchdog 线程做 last_seen 检测 + 超龄重建 subscriber，新增 `b2_dds_*` 4 路自检指标
- **W-2 GetSnapshot**：5 个 GetXxx → 单方法 GetSnapshot()，含两段时间戳和字段可用性 flag
- **W-5 命名规范**：完整 Prometheus 单位后缀（`_meters_per_second / _newton_meters / _radians_per_second`）

### 1.5 现场新发现（修复）

| 现象 | 根因 | 修复 |
|------|------|------|
| `cell_vol[14]=0` 让 min/diff 衍生指标污染 | B2 实际有效 14 节，第 15 节是预留槽 | `b2.go` cell voltage 衍生计算跳过 0 值 |
| Grafana 容器查 datasource 报 "proxyconnect tcp 127.0.0.1:7890" | Thor docker daemon 继承 sing-box 全局代理 | docker-compose 给 grafana / ros_exporter 显式 `NO_PROXY=vm,localhost,127.0.0.1` + 清空 `HTTP_PROXY/HTTPS_PROXY` |
| VM 容器 healthcheck 永久 unhealthy | VM 镜像基于 distroless，无 wget/curl | depends_on 改用 `service_started` |
| cgo 链接 `undefined reference ... GLIBCXX_3.4` | LDFLAGS 缺 `-lstdc++` | `internal/b2/dds_cgo.go` 加 `-lstdc++` |
